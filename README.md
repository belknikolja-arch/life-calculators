# Калькуляторы на все случаи жизни

Одностраничное веб-приложение в одном файле: **`index.html`**.
25 калькуляторов на каждый день: деньги, дом, еда, математика, здоровье.
Работает полностью локально (без серверов, зависимостей и внешних библиотек) —
просто откройте файл в браузере.

> 🔗 **Живая версия (демо онлайн):** https://belknikolja-arch.github.io/life-calculators/

## Калькуляторы (25)

**💰 Деньги (9)**
1. 🏦 Кредит — аннуитетный платёж, переплата, сумма выплат
2. 🏛️ Депозит — капитализация + ежемесячные взносы
3. 🧾 НДС: выделить из цены (сумма с налогом → база + НДС)
4. ➕ НДС: наложить сверху (база → сумма с налогом)
5. 💼 НДФЛ brutto/netto — заполняете одно, второе считается (13/15% и любые ставки)
6. ➗ Проценты — «X% от Y» и «A — сколько % от B»
7. 🏷️ Скидка — итоговая цена и выгода
8. ⏱️ Зарплата во времени — в час / день / неделю / год
9. 📉 Инфляция — покупательная способность суммы через N лет

**🏠 Дом (4)**
10. 📏 Комната — пол, периметр, стены, потолок
11. 🎨 Краска — литраж по укрывистости, слои, банки

**🍽️ Еда (3)**

## Как пользоваться

1. Откройте `index.html` (или живую версию).
2. Выберите категорию на чипах или найдите калькулятор поиском (например, «краска», «ИМТ», «чаевые»).
3. Поля заполнены разумными значениями по умолчанию — можно сразу жать «Рассчитать».
4. Под результатом — короткая подсказка про формулу и оговорки.

## Код

- Один HTML-файл: разметка + CSS + два скрипта.
- `<script id="core">` — чистые функции без DOM (аннуитет, НДС, ИМТ, TDEE, CSV-подобный парсинг чисел, даты…) — тестируются в Node.
- `<script>` — UI: общий генератор карточек по декларативным описаниям + отдельный билдер для рецепта (динамические строки ингредиентов).

## Формулы

- Кредит: аннуитет `P·r/(1−(1+r)^−n)`, r = ставка/12.
- Депозит: капитализация ежемесячно.
- НДС: база = сумма/(1+ставка).
- НДФЛ: net = gross·(1−ставка); gross = net/(1−ставка).
- BMR (Миффлин–Сан Жеора): `10·кг + 6.25·см − 5·лет + 5(м) / −161(ж)`; TDEE = BMR × коэффициент активности.
- ИМТ: `кг/м²`, категории ВОЗ.
- 1ПМ (Эйпли): `вес·(1+повторы/30)`.

## Ограничения

Бытовой ориентировочный инструмент, не финансовая, медицинская или налоговая консультация. Для больших сумм и серьёзных решений — к специалистам.
