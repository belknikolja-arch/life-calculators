# Калькуляторы на все случаи жизни

40 бытовых калькуляторов в 6 категориях. Доступны **две версии**:

- **Классическая** — один файл [`index.html`](index.html), без сборки и зависимостей: откройте в браузере — и всё работает офлайн.
- **Современная** — [React + TypeScript](web/) (Vite) с обновлённым дизайном и темой.

Общее для обеих версий:

- Работает локально, без интернета и без сервера (классическая — вообще без сборки)
- Тёмная/светлая тема, адаптивная вёрстка, работает с телефона
- **Память вводов**: значения калькуляторов запоминаются между визитами
- Детерминированный формат чисел (не зависит от локали системы)
- Дисклеймер: ориентиры для бытовых задач, не финансовая/медицинская/налоговая консультация

## Как пользоваться

1. Выберите категорию на панели — карточки фильтруются.
2. Заполните поля у калькулятора (значения сохраняются автоматически).
3. Жмите «Рассчитать» (или <kbd>Enter</kbd> внутри карточки) — результат появится с пояснением.
4. Кнопка «Сброс» возвращает значения по умолчанию.

## Современная веб-версия (React + TypeScript)

В папке [`web/`](web/) — переписанная версия сайта на **React + TypeScript** (сборка Vite)
с обновлённым дизайном: тёмная/светлая тема, поиск, фильтр по категориям,
карточки с анимациями, сохранение введённых значений.

```bash
cd web
npm install
npm run dev      # разработка (http://localhost:5173)
npm run build    # production-сборка в web/dist
```

Логика всех 40 калькуляторов вынесена в чистые модули `src/core.ts` и
`src/catalog.ts` и сверена с оригиналом (JS) автоматически: результаты совпадают
1-в-1, кроме трёх намеренно исправленных багов веб-версии (см. ниже).

## Известные баги оригинала (в классическом `index.html`), исправленные в React-версии

1. «Краска» показывала «Банок по 0 л» — теперь реальный объём банки.
2. «Стаканы ↔ граммы» теряла подсказку «1 стакан = N г» — теперь показывается.
3. «Роды» прятала сдвиг Нагеле в скрытом параметре — теперь сдвиг виден в подсказке.
