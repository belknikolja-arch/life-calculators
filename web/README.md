# Калькуляторы на все случаи жизни — React + TypeScript

Современная веб-версия 40 калькуляторов (v1.3) на **React 18 + TypeScript + Vite**.
Логика полностью переписана с JavaScript-оригинала (`index.html` в корне репозитория),
численные результаты сверены с оригиналом по всем калькуляторам.

## Что улучшено в дизайне (по сравнению с классической версией)

- Современный адаптивный UI: стеклянные карточки, градиенты, плавные анимации.
- Тёмная/светлая тема (сохраняется в браузере).
- Поиск и фильтр по категориям, счётчик «Показано: N из 40».
- Ввод через `<form>` — расчёт по Enter, живой результат, кнопка «Сброс».
- Память введённых значений (localStorage) у каждого калькулятора.
- Улучшенные подсказки и читаемые крупные результаты.

## Запуск

```bash
npm install
npm run dev      # режим разработки: http://localhost:5173
npm run build    # production-сборка в dist/
npm run preview  # просмотр собранной версии
```

## Структура

- `src/core.ts` — чистое ядро: все формулы (порт JS-ядра) + форматирование чисел.
- `src/catalog.ts` — 40 калькуляторов: поля, категории, функции результатов.
- `src/App.tsx` — приложение: поиск, фильтры, карточки, спец-карточки «Рецепт» и «Конвертер».
- `src/styles.css` — тема и оформление.

## Корректность

Вывод всех 40 калькуляторов сверен с оригиналом автоматически (Node + esbuild):
совпадает 1-в-1, кроме трёх намеренных исправлений багов классической версии —
см. «Известные баги оригинала» в корневом README.md.
